## How To Think About Overtime Requests
Submitting overtime creates a request for review. It does not guarantee approval, attendance adjustment, or payroll effect by itself.

## Important Workflow Rules
- `Pending` means the request is still active.
- `Approved` means the workflow accepted the request.
- `Rejected` means the request was reviewed and denied.
- Cancellation is usually limited to requests that are still pending.

## If The Result Looks Delayed
Check the current status first. If the request is already approved but the downstream record still looks wrong, that is no longer only a request issue and may need payroll or attendance review.
