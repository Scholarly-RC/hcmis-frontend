## What To Use This Page For
- See which evaluation cycles are available to your account.
- Identify whether a response or review is still required.
- Open the assigned evaluation task when action is pending.

## What The Status Usually Tells You
The page should make it clear whether the cycle is still in progress, already submitted, or only available for viewing.

## When To Escalate
Escalate when you expect to participate in a cycle but no assignment is visible, or when the cycle is visible but cannot be opened or submitted as expected.
