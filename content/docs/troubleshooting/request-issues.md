## The Most Common Request Problems
- A request stays pending longer than expected.
- A request can be viewed but not acted on.
- A request cannot be cancelled even though the user expects it to be open.

## What To Check First
- Confirm the current status.
- Confirm whether the current user is the active approver for that stage.
- Confirm whether the request is still in a state that allows cancellation or approval.

## When A Pending Request Is Normal
Pending only means the workflow is still open. It is not evidence of failure by itself.
