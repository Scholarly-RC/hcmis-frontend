## When This Page Appears
- Immediately after sign-in when the account must update its password before normal use.
- From `Profile` when the user chooses to change the password manually.

## What To Expect
The password change flow is part of account security, not a separate workflow. Once the change is accepted, HCMIS returns you to normal application use.

## If The Form Rejects The Change
Use the on-screen validation message as the source of truth. If the account is still unable to complete the required update, escalate it because access can remain blocked until the password change succeeds.
