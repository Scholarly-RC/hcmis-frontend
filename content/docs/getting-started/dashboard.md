## What Dashboard Is For
Dashboard is not a full workflow page. It is a launch point. It highlights high-signal items such as pending requests, attendance summaries, payroll visibility, or employee updates so users can move directly into the correct module.

## Why Different Users See Different Cards
- Employees usually see self-service shortcuts and personal summaries.
- HR and administrative users usually see approval queues, management shortcuts, and operational summaries.
- Missing cards usually mean the account does not have access to that workspace or that there is no current item to show.

## How To Use It Well
Open the linked module when a dashboard card indicates action is needed. Use the dashboard to prioritize work, not as a replacement for the detailed page where the workflow actually happens.
