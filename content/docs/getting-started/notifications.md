## What Notifications Mean
Notifications are attention signals, not the full record. They tell you that something changed, but the actual action still happens on the linked page such as a request inbox, payroll page, or announcement.

## Expected Behavior
- Unread items are visually distinct from previously opened items.
- Opening a notification can mark it as read.
- Some notifications navigate directly to a target page when that link is available.

## Common Confusion
If a notification exists but does not open the expected page, the notification may not include a target link or the target page may no longer be available to the current user.
