## How To Add A Shift
Open `Shift Management`, select the add shift action, enter the shift description, time ranges, and active status, then save the record. Confirm the new shift appears in the list with the expected schedule.

VIDEO: https://drive.google.com/file/d/1xFdhLPJxv57Y7xf4dd3ejRMidAWMUJe2/view?usp=drive_link

## How To Edit A Shift
Open `Shift Management`, find the shift you want to change, open the edit action, update the description, time ranges, or active status, then save the changes. Review the row after saving to confirm the updated values are reflected in the list.

VIDEO: https://drive.google.com/file/d/1IjSk6W8aOHkPbhA85HmVuKr_33uhfGKj/view?usp=drive_link

## How To Delete A Shift
Open `Shift Management`, find the shift you want to remove, open the delete action, and confirm the permanent delete prompt. Use this only when the shift is no longer needed and is not blocked by existing references.
