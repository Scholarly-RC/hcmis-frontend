## How To Add A User
Open `User Management`, use the add user action, enter the required account and employee details, then save the record. After saving, confirm the new user appears in the list with the expected role and active status.

VIDEO: https://youtu.be/Mr1cabNTJ3A

## How To Edit A User
Open `User Management`, find the user you need, open the edit action, update the allowed fields, and save the changes. Review the row again after saving to confirm the updated details are now reflected in the list.

## How To Reset A User Password
Open the target user record from `User Management`, go to the profile or security area where password reset is available, then perform the reset action. Confirm with the user afterward that they can sign in with the new or temporary password flow.

## How To Activate Or Deactivate A User
Find the user in `User Management`, open the action that changes account status, then switch the user to active or inactive as needed. Confirm the status shown in the list after saving so the account state matches the intended access level.

## How To Review A User Profile
Open `User Management` and select the user whose record needs deeper review. Use the profile page when the main table is not enough and you need to inspect managed details, account state, or related operational information.

## How To Open Biometric Sync From User Management
Locate the user in `User Management` and open the biometric-related action when you need to compare or follow up on matching between the app record and biometric data. Use this path when the issue is identity mapping or sync review rather than a normal profile update.
