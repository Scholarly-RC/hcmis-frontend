## What Makes This Different From Employee Attendance
- It supports broader operational review.
- It can be used to inspect mismatches and correction needs.
- It exists in the context of attendance administration rather than personal viewing.

## When To Use It
Use this page when attendance needs validation, correction, or administrative review across employees or periods.

## When Another Page Is Better
If the problem is only about understanding basic status meaning, start with the employee page or the shared attendance overview first.
