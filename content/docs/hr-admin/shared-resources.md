## What This Page Controls
- Which files are available in the shared resources area.
- Which audience can see each item.
- Whether a resource remains visible, updated, or removed.

## Why Visibility Matters
The employee side only shows content that has been intentionally published to that audience. A missing file can therefore be an access design decision, not a technical failure.
