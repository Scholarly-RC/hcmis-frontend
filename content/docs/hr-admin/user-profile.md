## What Belongs Here
- Reviewing the full employee record.
- Updating managed details that are not employee self-service.
- Performing account-level actions such as activation state or password reset.

## Why This Page Exists Separately
Broad lists are useful for discovery. A dedicated profile page is where higher-context decisions and employee-specific updates belong.

## Use Caution With Administrative Actions
Account-level changes affect access and downstream workflows, so confirm the right employee record before applying them.
