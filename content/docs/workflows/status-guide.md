## Common Status Meanings
- `Pending`: the request is still active and waiting on a workflow action.
- `Approved`: the request completed successfully in the workflow.
- `Rejected`: the request was reviewed and denied.
- `Cancelled`: the request was withdrawn or closed before normal completion.

## How To Read Status Correctly
Status matters together with context. A `Pending` request can be normal if it is still in the expected review stage. A resolved status with a wrong downstream record usually means the issue moved beyond the request itself.

## Use The Status Before Taking Action
Always confirm the current status before resubmitting, escalating, or assuming a page is malfunctioning.
