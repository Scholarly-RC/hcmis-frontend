## What Request Inbox Answers
- Is the request still active?
- Who currently needs to act on it?
- Is the current user allowed to approve, reject, or cancel it?

## How To Read A Request
Use the current status, approver information, and request details together. A request can be visible but not actionable if it already moved to another approver or has already been resolved.

## Why Action Buttons Can Be Missing
- The request is no longer pending.
- The request belongs to another approver in the current stage.
- The current user can view the request but is not the active actor for that step.
