## Shared Workflow Model
1. A user submits a request.
2. The request enters one or more review stages.
3. The active approver acts on the request or leaves it pending.
4. The workflow resolves as approved, rejected, cancelled, or another final state defined by the module.

## What Pending Actually Means
`Pending` does not mean broken. It means the request is still active and awaiting the next workflow action.

## Where To Follow Progress
Use the source request page or `Request Inbox` to see the latest visible state. The workflow pages are the right place to interpret status; dashboard cards and notifications are only pointers.
